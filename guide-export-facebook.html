Récupérer l'export de vos conversations Facebook

Dernière mise à jour : 23 novembre 2026

Facebook vous permet de télécharger une copie de vos conversations Messenger. Voici comment l'obtenir au bon format, sur ordinateur ou sur iPhone, pour l'importer ensuite dans Reminds.

  • Avant de commencer
  • Sur ordinateur
  • Sur iPhone
  • Discussions chiffrées
  • Dans Reminds

Avant de commencer

  • Il vous faut votre mot de passe Facebook et l'accès à votre boîte e-mail.
  • Sur ordinateur, c'est plus simple : l'export peut peser plusieurs gigaoctets.
  • Les quatre réglages qui comptent : Messages seulement, Depuis le début, format JSON, Qualité supérieure.
  • Les noms, adresses et photos de ces captures sont masqués ou remplacés par des exemples.

1. Sur ordinateur

Sur facebook.com, dans un navigateur. Les écrans peuvent légèrement changer selon les versions de Facebook.

  1. Ouvrez le menu de votre profil

    Sur facebook.com, cliquez sur votre photo de profil en haut à droite, puis sur « Paramètres et confidentialité ».

  2. Ouvrez les paramètres

    Cliquez sur « Paramètres ».

  3. Allez dans le Compte Meta

    Dans la colonne de gauche, sous « Votre compte », cliquez sur « Compte Meta ».

  4. Vos informations et autorisations

    Cliquez sur « Vos informations et autorisations », puis sur « Exporter vos informations ».

  5. Créez une exportation

    Cliquez sur « Créer une exportation ».

  6. Choisissez votre profil Facebook

    Sélectionnez le profil Facebook qui contient vos conversations (pas Instagram ni WhatsApp).

  7. Exportez sur votre appareil

    Choisissez « Exporter sur mon appareil » : vous téléchargerez vous-même le fichier.

  8. Le récapitulatif : quatre réglages à changer

    Le récapitulatif montre ce qui sera exporté. Réglez les quatre lignes encadrées, une par une : informations, période, format et qualité.

  9. Gardez seulement les messages

    Dans « Personnaliser les informations », si tout est coché, cliquez sur « Tout effacer », puis cochez uniquement « Messages ». Cliquez sur « Enregistrer ».

  10. Toute la période

    Dans « Période », choisissez « Depuis le début », puis « Enregistrer ». Sinon, seule la dernière année est exportée.

  11. Le format JSON

    Dans « Format », choisissez « JSON », puis « Enregistrer ». C'est indispensable : Reminds lit le format JSON, pas le HTML.

  12. La meilleure qualité

    Dans « Qualité des contenus multimédias », choisissez « Qualité supérieure », puis « Enregistrer ». Vos photos et vidéos gardent leur qualité.

  13. Lancez l'exportation

    Vérifiez les quatre lignes (Messages, Depuis le début, JSON, Qualité supérieure), puis cliquez sur « Commencer l'exportation ».

  14. Confirmez avec votre mot de passe

    Pour votre sécurité, Facebook vous redemande votre mot de passe. Saisissez-le, puis « Continuer ».

  15. L'export est en attente

    L'export apparaît « En attente » : Facebook prépare vos fichiers. Selon la taille de votre historique, cela prend de quelques minutes à plusieurs heures. Vous pouvez fermer la page.

  16. Un premier e-mail de confirmation

    Facebook vous envoie un e-mail « Votre demande de téléchargement Meta est en cours ». Rien à faire pour l'instant.

  17. L'e-mail « fichiers prêts »

    Quand l'export est prêt, un second e-mail arrive. Cliquez sur le lien « Exporter vos informations ».

  18. Téléchargez le fichier

    Sous « Téléchargements disponibles », cliquez sur « Télécharger ». Facebook peut découper l'export en plusieurs fichiers zip : téléchargez-les tous, puis importez-les un par un dans Reminds. Ils restent disponibles 4 jours.

2. Sur iPhone

Dans l'app Facebook pour iPhone. La fin du parcours s'ouvre dans le navigateur intégré à l'app.

  1. Ouvrez le menu

    Dans l'app Facebook, touchez le menu (les trois traits).

  2. Paramètres et confidentialité

    Faites défiler et touchez « Paramètres et confidentialité ».

  3. Paramètres

    Touchez « Paramètres ».

  4. Compte Meta

    Sous « Votre compte », touchez « Compte Meta ».

  5. Vos informations et autorisations

    Touchez « Vos informations et autorisations ».

  6. Exporter vos informations

    Touchez « Exporter vos informations ».

  7. Reconnectez-vous si besoin

    La page s'ouvre dans le navigateur intégré à l'app. Facebook peut vous demander de vous reconnecter : saisissez votre e-mail ou numéro et votre mot de passe, puis « Se connecter ».

  8. « Plus tard »

    Si Facebook propose d'enregistrer vos infos de connexion, touchez « Plus tard ».

  9. Créez une exportation

    Touchez « Créer une exportation ».

  10. Choisissez votre profil Facebook

    Touchez votre profil Facebook (pas Instagram ni WhatsApp).

  11. Exportez sur votre appareil

    Touchez « Exporter sur mon appareil ».

  12. Quatre réglages à changer

    Par défaut, Facebook propose toutes les informations, l'année dernière, le format HTML et une qualité moyenne. Changez les quatre lignes encadrées.

  13. Tout décocher

    Dans « Personnaliser les informations », touchez « Tout effacer ».

  14. Cochez seulement Messages

    Cochez uniquement « Messages », puis « Enregistrer ».

  15. Depuis le début

    Dans « Période », choisissez « Depuis le début », puis « Enregistrer ».

  16. JSON

    Dans « Format », choisissez « JSON », puis « Enregistrer ».

  17. Qualité supérieure

    Dans « Qualité des contenus multimédias », choisissez « Qualité supérieure », puis « Enregistrer ».

  18. Lancez l'exportation

    Vérifiez : Messages, Depuis le début, JSON, Qualité supérieure. Touchez « Commencer l'exportation ». Facebook peut redemander votre mot de passe.

  19. E-mail de confirmation

    Un premier e-mail confirme que la demande est en cours. Patientez.

  20. La notification

    Quand l'export est prêt, Facebook vous envoie une notification.

  21. Téléchargez les fichiers

    Ouvrez l'e-mail « fichiers prêts » et touchez « Exporter vos informations », puis « Télécharger ». Sur iPhone, le zip arrive dans l'app Fichiers. S'il y a plusieurs fichiers, téléchargez-les tous (4 jours pour le faire).

3. Discussions chiffrées de bout en bout Expérimental

Messenger chiffre de bout en bout une partie des discussions. Leurs messages peuvent manquer dans l'export ci-dessus. Facebook propose un téléchargement séparé, que Reminds lit à titre expérimental.

  1. Restaurez l'historique de vos discussions

    Sur ordinateur, ouvrez Messenger (facebook.com/messages). Si Facebook le demande, restaurez l'historique de vos discussions chiffrées : cliquez sur « Envoyer le code » pour recevoir un code à usage unique dans l'app Messenger ou Facebook de votre téléphone, ou saisissez votre code PIN.

  2. Téléchargez les discussions sécurisées

    Dans les paramètres de Messenger, ouvrez « Confidentialité et sécurité », puis « Discussions chiffrées de bout en bout », « Stockage des messages » et « Télécharger les données du stockage sécurisé ». Les intitulés exacts peuvent varier selon les versions.

  3. Importez ce fichier dans Reminds

    Importez-le comme les autres, à la suite de l'export classique.

4. Puis dans Reminds Bientôt disponible

L'import depuis l'app est en dernière phase de tests. Dès qu'il est ouvert :

  1. Ouvrez Reminds

    Sur le web ou sur iPhone, connectez-vous avec votre adresse e-mail.

  2. Touchez « Importer »

    Choisissez le fichier zip téléchargé depuis Facebook.

  3. Choisissez vos conversations

    Reminds liste les conversations trouvées dans le zip : choisissez celles à garder et indiquez qui vous êtes.

  4. Plusieurs fichiers ?

    Importez chaque zip, un par un. Reminds ajoute ce qui manque, sans jamais rien effacer.
